# Gestion Ferme — Moutons & Chèvres

Application web de gestion et de suivi d'un élevage de moutons et chèvres :
animaux (fiches individuelles et lots), ventes & achats, stocks, dépenses,
mortalités, tableau de bord. Montants en FCFA. Interface en français.

## Utilisation

Ouvrir `index.html` dans un navigateur, ou visiter le site GitHub Pages du dépôt.

Les données vivent dans la page : utilisez **Exporter les données** (JSON)
pour sauvegarder, puis **Importer une sauvegarde** pour reprendre le travail.
Des exports CSV (Excel) sont disponibles dans l'onglet Données.

## Hébergement (GitHub Pages)

1. Créer un dépôt et y déposer `index.html` et ce `README.md`.
2. Settings → Pages → Source : branche `main`, dossier `/ (root)` → Save.
3. Le site sera disponible à `https://<votre-nom>.github.io/<nom-du-depot>/`.
